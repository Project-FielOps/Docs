# Caminhos de compatibilidade

Os diretórios `product/`, `requirements/`, `architecture/`, `engineering/`, `planning/`, `specs/` e `knowledge-base/` mantêm links simbólicos para documentos que foram consolidados em `_KB/`.

Eles não são fontes de verdade e não devem receber novos documentos. Use `_KB/` para conteúdo atual, `references/` para material histórico, `decisions/` para pendências e `01-tap/`/`02-eap/`/`03-cronograma/` para artefatos acadêmicos.
