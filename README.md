# Docs — Projeto FieldOps

Documentação de **gestão de projeto** do Projeto FieldOps, produzida para as atividades da disciplina **Gestão de Projetos** (SENAI, prof. Deivison Takatu), referentes às Aulas 2, 3 e 4.

Os artefatos técnicos e de código do FieldOps vivem nos repositórios `API` e `interface-administrativa` desta organização; este repositório concentra apenas a documentação de gestão (TAP, EAP, cronograma) e serve como fonte única de verdade para acompanhamento do projeto.

## Nota sobre o "PII deste semestre"

O TAP da Aula 2 pede dois documentos: um referente ao "PII deste semestre" e outro referente ao Projeto FieldOps. Neste caso os dois **são o mesmo projeto** — o FieldOps é o próprio Projeto Integrador II do semestre — por isso os dois TAPs tratam do FieldOps sob duas óticas complementares (acadêmica vs. produto), em vez de dois projetos distintos.
