# Fontes preservadas

Esta área é um acervo de origem, não uma segunda especificação vigente. Contém cópias integrais da base fornecida, incluindo suas contradições, e materiais anteriores à reorganização.

- [Índice original da base](base_fieldops/Projeto%20FieldOps%203022594f77cf8233a662814f75a0600f.md).
- [Manifesto SHA-256](source-manifest.json): permite verificar os 25 arquivos importados sem alterar os originais externos.
- [Análise secundária anterior](analysis-original.md): registra inferências históricas; não é evidência do estado atual das aplicações.
- O backlog derivado e o snapshot anterior não estão presentes neste checkout; não são usados como fonte de requisitos.

As fontes de origem são preservadas byte a byte. Exemplos, links externos, datas, afirmações de conclusão e propostas nelas presentes não são automaticamente compromissos atuais. A precedência vigente está em [fontes e manutenção](../_KB/99-reference/knowledge-base-maintenance.md).
