# FO-011 — Integração E2E da jornada vertical

**Prioridade:** P0 · **Estado:** BLOCKED por FO-002/003/007/008/009/010 · **Área:** Todas

## Objetivo

Validar a jornada real: planejamento web → execução mobile offline → sync → revisão web.

## Cenário obrigatório

1. ADMIN prepara usuário, cliente, local, equipamento e modelo.
2. SUPERVISOR agenda inspeção para técnico e supervisor válidos.
3. Técnico recebe e baixa a inspeção.
4. Técnico inicia, responde checklist, cria NC e anexa evidência offline.
5. App é reiniciado sem perder dados.
6. Técnico reconecta e sincroniza sem duplicidade.
7. Supervisor vê respostas/evidências no web.
8. Supervisor aprova ou reprova com motivo.
9. Reprovação chega ao técnico e permite reabertura explícita.

## Ferramentas e evidências

- Playwright para todo o percurso web.
- Runner E2E Android aprovado para o mobile.
- API real em ambiente controlado, banco isolado e dados descartáveis.
- Relatório com screenshots, vídeos/traces, request IDs e estado final.

## Critério de aceite

Nenhuma etapa pode ser substituída por fixture de sucesso. Falha parcial, 401, 403, 409, offline, retry e reinício devem ter cenário coberto.
