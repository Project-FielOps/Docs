# FO-010 — Autorização e proteção de dados/evidências

**Prioridade:** P0 · **Estado:** READY · **Área:** API/web/mobile

## Objetivo

Provar que papel, atribuição, status e imutabilidade são aplicados no backend e refletidos no frontend.

## Escopo

- Matriz ADMIN, SUPERVISOR e TECHNICIAN.
- Testes por objeto para inspeção, resposta, evidência, NC, revisão e histórico.
- Bloqueio após aprovação/cancelamento.
- Proibição de remoção indevida de evidência sincronizada.
- UI não deve exibir ação que a API rejeita, mas deve tratar 403/409.

## Testes obrigatórios

- Testes adversariais API com usuário atribuído, não atribuído, inativo e papel errado.
- Playwright autenticado com perfis diferentes.
- E2E mobile tentando abrir inspeção de outro técnico.
- Verificação de que dados sensíveis não aparecem em logs, mensagens ou snapshots.
