# FO-002 — Planejamento e usuários atribuíveis

**Prioridade:** P0 · **Estado:** BLOCKED até contrato autorizado · **Área:** Web/API

## Objetivo

Permitir que ADMIN e SUPERVISOR autorizados agendem inspeções com técnicos e supervisores ativos, sem abrir gestão administrativa de usuários.

## Contrato necessário

Definir consulta paginada de atribuíveis por papel, status e escopo. O endpoint deve informar somente usuários permitidos para o ator autenticado.

## Escopo web

- Remover dependência de `GET /users` para planejamento.
- Implementar seleção paginada, loading, vazio, erro e preservação da seleção.
- Validar cliente → local → equipamento → modelo → técnico → supervisor.
- Enviar `scheduledFor` em ISO-8601 com timezone.

## Critérios de aceite

- Supervisor agenda sem 403.
- Usuário inativo, ADMIN ou fora do escopo não aparece nem é aceito pela API.
- Lista com mais de 200 usuários não perde opções.
- Falha de uma seleção não apaga as anteriores.

## Testes obrigatórios

- Unitários de serviço, formulário e cascatas.
- Contrato API para papel, status e paginação.
- Playwright para ADMIN e SUPERVISOR, incluindo 403 e lista vazia.
- Teste E2E cria inspeção real e confirma detalhe retornado.
