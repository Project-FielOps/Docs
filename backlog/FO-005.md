# FO-005 — Recuperação e troca de senha

**Prioridade:** P0 · **Estado:** DONE · **Área:** Angular/API

## Objetivo

Expor no web os fluxos reais de recuperação, reset e troca obrigatória de senha.

## Escopo

- Tela de solicitação de recuperação sem enumeração de usuário.
- Tela de reset com token, validação de força e confirmação.
- Tela de troca obrigatória após login temporário.
- Mensagens para token expirado, usado e inválido.

## Testes obrigatórios

- Unitários de validação e serviços.
- Testes HTTP de payload e respostas anti-enumeração.
- Playwright para solicitação, reset válido/inválido e redirect obrigatório.
- Não registrar senha ou token em logs, URL após consumo ou analytics.

## Evidência de conclusão

- API: `mvn clean test` com 44 testes e `mvn clean package` concluído.
- Web: 38 testes unitários, build e Prettier concluídos.
- Playwright: 23/23 cenários passando, incluindo regressões FO-001–FO-004.
- Validação independente backend e web: `APPROVED_WITH_WARNINGS`.

Ressalvas não bloqueantes: o access token já emitido permanece válido até expirar, e o
Playwright web foi executado com mocks HTTP porque a API local não estava disponível.
