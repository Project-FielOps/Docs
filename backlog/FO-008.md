# FO-008 — Sync incremental, NC e conflitos

**Prioridade:** P0 · **Estado:** BLOCKED por contrato API · **Área:** API/mobile

## Objetivo

Fechar push/pull, mudanças remotas, NC offline, replay idempotente e conflitos sem descarte de trabalho.

## Escopo

- Feed de atribuição, cancelamento, revisão e revogação de escopo.
- Operação idempotente para criar/atualizar NC.
- Cursor só avança após persistência.
- Resultados por operação: aplicado, já aplicado, rejeitado, conflito e dependência falha.
- UI de sync mostra fila, erro, retry e conflito.

## Critérios de aceite

- Reenvio da mesma operação não duplica resposta, NC ou transição.
- Falha parcial preserva operações posteriores na fila.
- Mudança remota chega ao técnico autorizado.
- Conflito é explícito e nunca sobrescreve silenciosamente o dado local.

## Testes obrigatórios

- API com Testcontainers para replay, cursor, dependência e autorização.
- Testes mobile da máquina de estados de sync.
- Playwright para tela administrativa de status quando aplicável.
- E2E Android com perda de rede, retry, conflito e decisão remota.
