# FO-012 — Publicação e operação do frontend

**Prioridade:** P1 · **Estado:** BLOCKED por infraestrutura · **Área:** Web/DevOps

## Objetivo

Publicar o painel com HTTPS, refresh de rota, configuração de API segura, observabilidade e rollback.

## Escopo

- Build de produção sem URLs locais.
- S3 privado + CloudFront ou arquitetura aprovada equivalente.
- CORS restrito ao domínio do web.
- Fallback de rota SPA para refresh direto.
- Cache de assets com invalidação e rollback.
- Smoke HTTPS e verificação de headers de segurança.

## Testes obrigatórios

- Build de produção e análise de configuração.
- Playwright contra HTTPS publicado: login, refresh de rota, logout e jornada crítica.
- Smoke de CORS, cache, status code, certificado e headers.
- Registro de rollback reproduzível e evidência de recuperação.
