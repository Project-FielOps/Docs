# FO-006 — Qualidade frontend, acessibilidade e regressão visual

**Prioridade:** P0 · **Estado:** DONE · **Área:** Web

## Objetivo

Criar o gate permanente de qualidade do painel e provar que o web segue o Precision System do mobile.

## Escopo

- Adicionar Playwright configurado para Chromium e viewport mobile/desktop.
- Cobrir teclado, foco, labels, contraste, touch targets e estados sem depender só de cor.
- Criar snapshots visuais de login, shell, dashboard, lista, detalhe e revisão.
- Adicionar `axe-playwright` ou equivalente para WCAG 2.1 AA.
- Corrigir warnings de build e orçamento de estilos quando possível.

## Critérios de aceite

- CI executa unit, build, Prettier e Playwright.
- Não há regressão visual não aprovada nos snapshots.
- Fluxos críticos funcionam por teclado.
- Falhas de API têm mensagem próxima da ação/campo.

## Testes obrigatórios

`npm test -- --watch=false`, `npm run build`, `npx prettier --check src`, Playwright, axe e execução em viewport 390x844 e desktop.

## Evidência de conclusão

- Web: 38 testes unitários, build sem warnings e Prettier concluído.
- Playwright FO-006: 12/12 cenários passando contra API/PostgreSQL reais, em Chromium desktop e viewport móvel explícito de 390x844.
- Acessibilidade: axe com tags WCAG 2.1 A/AA sem violações nos seis fluxos; teclado, foco, labels, erros associados e tabela nomeada cobertos.
- Regressão visual: snapshots versionados de login, shell, dashboard, lista, detalhe e revisão, com dados temporais mascarados apenas nos trechos voláteis.
- Design system: tipografia global alinhada a Nunito Sans e style budget sem warnings.
- Validação independente Web QA: `APPROVED_WITH_WARNINGS`.

Risco residual não bloqueante: a suíte global ainda apresenta flake preexistente no cenário `fo-004-lists` desktop; a suíte específica da FO-006 permanece 12/12.
