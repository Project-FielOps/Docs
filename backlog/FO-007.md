# FO-007 — Persistência offline do mobile

**Prioridade:** P0 · **Estado:** BLOCKED por sessão/contrato · **Área:** React Native

## Objetivo

Substituir cache/fila simplificados por armazenamento local transacional, versionado e isolado por usuário/dispositivo.

## Escopo

- SQLite para inspeções, snapshots, respostas, evidências locais e outbox.
- Migrações retomáveis após reinício.
- Outbox com dependências, tentativas, erro, conflito e idempotency key.
- Logout não pode expor cache de outra conta nem apagar trabalho pendente sem ação explícita.

## Critérios de aceite

- Checklist e evidência sobrevivem a encerramento/reabertura do app offline.
- Uma resposta substituída não cria operações conflitantes desnecessárias.
- Dados de duas contas nunca são misturados.
- Estado local `pending` não é apresentado como enviado pelo servidor.

## Testes obrigatórios

- Testes unitários de repositórios, migrações e fila.
- Teste de reinício com armazenamento real/emulador.
- E2E Android offline → resposta → reinício → online → sync.
- Teste de logout/troca de conta e isolamento de dados.
