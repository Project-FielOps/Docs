# Arquitetura

Use `system-overview.md` para a visão geral, `backend.md`/`frontend.md`/`mobile.md` para as aplicações, `data-model.md` para dados e `aws.md` para a topologia cloud. Os padrões visuais estão em `WEB_DESIGN_SYSTEM.md` para a interface administrativa e `DESIGN_SYSTEM.md` para o aplicativo mobile. Decisões normativas ficam em `../12-decisions/`.

Documentos de arquitetura devem separar estado atual (`AS-IS`), arquitetura desejada (`TO-BE`) e decisão aprovada. Uma proposta não pode ser descrita como recurso provisionado.
