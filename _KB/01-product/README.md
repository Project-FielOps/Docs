# Produto e requisitos

Esta pasta contém o comportamento esperado do produto. Comece por `product-overview.md` e `product-mvp.md`; use `product-business-rules.md` para RN e os arquivos `requirements-*` para FR, requisitos não funcionais e rastreabilidade.

Para o catálogo completo de telas, permissões, funcionalidades e critérios de aceite, consulte [Especificação de telas e funcionalidades](application-scope-and-screen-specification.md). A validação da superfície atual está em [Validação de páginas e funcionalidades](../99-reference/validation/application-surface-validation-2026-09-07.md).

Para o detalhamento exclusivo do aplicativo Android, consulte [Especificação funcional do Mobile](mobile-screen-specification.md).

`business-rules.md` e `requirements.md` são resumos legados mantidos por compatibilidade. Não crie uma nova regra neles; atualize os documentos canônicos acima.
